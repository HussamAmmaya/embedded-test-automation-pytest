Project: Arduino Serial Automation

Goal:
Read Serial data from Arduino using Python.

Important:
- Arduino sends data using Serial.println()
- Python reads data using pyserial
- Baud rate must be same in Arduino and Python: 9600
- Serial Monitor must be closed before running Python
- Correct COM port must be selected
- Arduino is case-sensitive: Serial is correct, serial is wrong

Current result:
Python successfully reads LED ON / LED OFF from Arduino.
